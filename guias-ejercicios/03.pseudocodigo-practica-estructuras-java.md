# Guía de Pseudocódigo — Ejercicios de Práctica en Java
## Orientación para resolver cada ejercicio

> Este documento te da la lógica de solución en pseudocódigo — no el código Java. La idea es que pienses el algoritmo antes de escribirlo en Java. Tradúcelo tú mismo a código: es la mejor forma de aprender.

---

## Bloque 1: Estructura secuencial

---

### Ejercicio 1.1 — Conversión de temperatura

```
INICIO
  Leer celsius (double)

  fahrenheit = (celsius * 9/5) + 32
  kelvin     = celsius + 273.15

  Imprimir celsius con 2 decimales
  Imprimir fahrenheit con 2 decimales
  Imprimir kelvin con 2 decimales
FIN
```

> Pista Java: usa `System.out.printf("%.2f", valor)` para dos decimales.

---

### Ejercicio 1.2 — Cálculo de nómina básica

```
INICIO
  Leer nombre (texto)
  Leer horas (número)
  Leer valorHora (número)

  salarioBruto = horas * valorHora
  descuentoSS  = salarioBruto * 0.08
  retencion    = salarioBruto * 0.05
  salarioNeto  = salarioBruto - descuentoSS - retencion

  Imprimir nombre, salarioBruto, descuentoSS, retencion, salarioNeto
FIN
```

---

### Ejercicio 1.3 — Área y perímetro de figuras

```
INICIO
  Leer base, altura (rectángulo)
  Leer radio (círculo)

  areaRectangulo      = base * altura
  perimetroRectangulo = 2 * (base + altura)
  areaCirculo         = PI * radio * radio
  circunferencia      = 2 * PI * radio

  Imprimir areaRectangulo, perimetroRectangulo
  Imprimir areaCirculo, circunferencia
FIN
```

> Pista Java: `Math.PI` y `Math.pow(radio, 2)` o simplemente `radio * radio`.

---

### Ejercicio 1.4 — Tiempo de viaje

```
INICIO
  Leer minutos (entero)

  segundosTotales = minutos * 60

  horas    = minutos / 60           // división entera
  minResto = minutos % 60           // módulo
  segResto = segundosTotales % 60

  Imprimir horas, minResto, segResto
  Imprimir segundosTotales
FIN
```

> Recuerda: en Java, dividir dos `int` da como resultado un `int` (se pierden los decimales) — eso es justo lo que necesitas aquí.

### Ejercicio 1.5 — Promedio ponderado de un estudiante

```
INICIO
  Leer p1, p2, pf (tres notas)

  definitiva = (p1 * 0.30) + (p2 * 0.30) + (pf * 0.40)

  // Sin usar if: resolver con operador ternario
  estado = (definitiva >= 3.0) ? "Aprobado" : "Reprobado"

  Imprimir definitiva con 2 decimales
  Imprimir estado
FIN
```

> El operador ternario tiene la forma: `condición ? valorSiTrue : valorSiFalse`

### Ejercicio 2.1 — Clasificación de triángulos

```
INICIO
  Leer a, b, c (tres lados)

  esValido = (a + b > c) Y (a + c > b) Y (b + c > a)

  SI NO esValido ENTONCES
    Imprimir "No es un triángulo válido"
  SI NO
    SI a == b Y b == c ENTONCES
      Imprimir "Equilátero"
    SI NO SI a == b O b == c O a == c ENTONCES
      Imprimir "Isósceles"
    SI NO
      Imprimir "Escaleno"
    FIN SI
  FIN SI
FIN
```

> Piensa primero: ¿qué condición matemática garantiza que tres segmentos SÍ formen un triángulo? Esa validación va antes de clasificar.

### Ejercicio 2.2 — Calculadora de IMC

```
INICIO
  Leer peso, estatura

  imc = peso / (estatura * estatura)

  SI imc < 18.5 ENTONCES
    categoria = "Bajo peso"
  SI NO SI imc <= 24.9 ENTONCES
    categoria = "Peso normal"
  SI NO SI imc <= 29.9 ENTONCES
    categoria = "Sobrepeso"
  SI NO
    categoria = "Obesidad"
  FIN SI

  Imprimir imc, categoria
FIN
```

> Nota el orden de las comparaciones: como usas `else if` en cadena, no necesitas escribir el límite inferior de cada rango — si llegó hasta ahí es porque ya no cumplió el rango anterior.

### Ejercicio 2.4 — Tarifa de parqueadero

```
INICIO
  Leer tipo (1, 2 o 3)
  Leer horas

  SEGÚN tipo HACER
    CASO 1: primeraHora = 2000, horaAdicional = 1500
    CASO 2: primeraHora = 4000, horaAdicional = 3000
    CASO 3: primeraHora = 5000, horaAdicional = 4000

### Ejercicio 2.5 — Año bisiesto y día de la semana

```
INICIO
  Leer anio

  bisiesto = (anio % 4 == 0) Y (anio % 100 != 0 O anio % 400 == 0)

  Imprimir anio, bisiesto ? "es bisiesto" : "no es bisiesto"

  Leer dia (1 a 7)

  SEGÚN dia HACER

### Ejercicio 3.1 — Tabla de multiplicar extendida

```
INICIO
  Leer n

  // Tabla simple del 1 al 12
  PARA i DESDE 1 HASTA 12 HACER
    Imprimir (n * i) alineado
  FIN PARA

  // Cuadrícula: tablas del 1 al n
  PARA fila DESDE 1 HASTA n HACER
    PARA columna DESDE 1 HASTA 12 HACER
      Imprimir (fila * columna) alineado
    FIN PARA
    Salto de línea
  FIN PARA
FIN
```

> Pista Java: usa `System.out.printf("%4d", numero)` para alinear los números en columnas de ancho fijo.

### Ejercicio 3.2 — Adivina el número

```
INICIO
  secreto = numero aleatorio entre 1 y 100
  intentos = 0

  HACER
    Leer numero (intento del usuario)
    intentos = intentos + 1

    SI numero > secreto ENTONCES
      Imprimir "El número es menor"
    SI NO SI numero < secreto ENTONCES
      Imprimir "El número es mayor"
    SI NO
      Imprimir "¡Correcto! " + intentos + " intentos"
    FIN SI

  MIENTRAS numero != secreto
FIN
```

> Pista Java: `(int)(Math.random() * 100) + 1` genera un entero aleatorio entre 1 y 100. Usa un `do-while` porque necesitas leer al menos un intento antes de poder evaluar la condición de salida.

### Ejercicio 3.3 — Suma de series matemáticas

```
INICIO
  Leer n

  // Serie 1: naturales
  sumaNaturales = 0
  PARA i DESDE 1 HASTA n HACER
    sumaNaturales = sumaNaturales + i
  FIN PARA
  formulaNaturales = n * (n + 1) / 2

  // Serie 2: pares
  sumaPares = 0
  PARA i DESDE 1 HASTA n HACER
    sumaPares = sumaPares + (2 * i)
  FIN PARA
  formulaPares = n * (n + 1)

  // Serie 3: cuadrados
  sumaCuadrados = 0
  PARA i DESDE 1 HASTA n HACER
    sumaCuadrados = sumaCuadrados + (i * i)
  FIN PARA
  formulaCuadrados = n * (n + 1) * (2n + 1) / 6

  Imprimir cada suma junto a su fórmula, para verificar que coinciden
FIN
```

### Ejercicio 3.4 — Validación de entrada con while

```
INICIO
  edad = -1   // valor inicial inválido a propósito, para entrar al ciclo

  MIENTRAS edad < 1 O edad > 120 HACER
    Leer edad
    SI edad < 1 O edad > 120 ENTONCES
      Imprimir "Edad inválida, intenta de nuevo"
    FIN SI
  FIN MIENTRAS

  SI edad <= 12 ENTONCES
    etapa = "Niñez"
  SI NO SI edad <= 17 ENTONCES
    etapa = "Adolescencia"
  SI NO SI edad <= 25 ENTONCES
    etapa = "Juventud"
  SI NO SI edad <= 59 ENTONCES
    etapa = "Adultez"
  SI NO
    etapa = "Tercera edad"
  FIN SI

  Imprimir edad, etapa
FIN
```

> La clave de este ejercicio es que el `while` se repite MIENTRAS el dato sea inválido — no esperes a que el usuario acierte, tú decides cuándo parar según la condición.

### Ejercicio 3.5 — Números primos en un rango

```
INICIO
  Leer a, b

  cantidad = 0
  suma = 0
  listaPrimos = vacía

  PARA numero DESDE a HASTA b HACER
    SI numero < 2 ENTONCES
      SIGUIENTE ITERACIÓN   // 0 y 1 no son primos, salta al siguiente número
    FIN SI

    esPrimo = verdadero
    divisor = 2

    MIENTRAS divisor <= raizCuadrada(numero) Y esPrimo HACER
      SI numero % divisor == 0 ENTONCES
        esPrimo = falso       // encontró un divisor exacto, no es primo
      FIN SI
      divisor = divisor + 1
    FIN MIENTRAS

    SI esPrimo ENTONCES
      Agregar numero a listaPrimos
      cantidad = cantidad + 1
      suma = suma + numero
    FIN SI
  FIN PARA

  Imprimir listaPrimos, cantidad, suma
FIN
```

> Pista clave: un número es primo si NINGÚN valor entre 2 y su raíz cuadrada lo divide exactamente. No necesitas revisar más allá de la raíz cuadrada — es una optimización importante.

## Bloque 4: Arreglos y matrices

---

### Ejercicio 4.1 — Estadísticas de un grupo

```
INICIO
  Crear arreglo notas de tamaño 10

  PARA i DESDE 0 HASTA 9 HACER
    Leer notas[i]
  FIN PARA

  suma = 0
  masAlta = notas[0], posAlta = 0
  masBaja = notas[0], posBaja = 0
  aprobados = 0, reprobados = 0

  PARA i DESDE 0 HASTA 9 HACER
    suma = suma + notas[i]

    SI notas[i] > masAlta ENTONCES
      masAlta = notas[i]
      posAlta = i
    FIN SI

    SI notas[i] < masBaja ENTONCES
      masBaja = notas[i]
      posBaja = i
    FIN SI

    SI notas[i] >= 3.0 ENTONCES
      aprobados = aprobados + 1
    SI NO
      reprobados = reprobados + 1
    FIN SI
  FIN PARA

  promedio = suma / 10

  Imprimir promedio, masAlta con posAlta, masBaja con posBaja, aprobados, reprobados
FIN
```

> Todo se puede calcular en un solo recorrido del arreglo — no necesitas un `for` separado para cada estadística.

### Ejercicio 4.2 — Inversión de un arreglo

```
INICIO
  Leer n
  Crear arreglo de tamaño n

  PARA i DESDE 0 HASTA n-1 HACER
    Leer arreglo[i]
  FIN PARA

  Imprimir arreglo (original)

  // Invertir SIN arreglo auxiliar: intercambiar extremos hacia el centro
  PARA i DESDE 0 HASTA (n/2 - 1) HACER
    temp            = arreglo[i]
    arreglo[i]      = arreglo[n - 1 - i]
    arreglo[n-1-i]  = temp
  FIN PARA

  Imprimir arreglo (invertido)
FIN
```

> Dibuja el arreglo en papel con posiciones `0, 1, 2, 3, 4` para un `n=5` y verifica manualmente qué posición se intercambia con cuál. Solo necesitas llegar hasta la mitad — si sigues de largo, deshaces lo que ya invertiste.

### Ejercicio 4.3 — Búsqueda en arreglo de nombres

```
INICIO
  Crear arreglo pacientes de tamaño 8

  PARA i DESDE 0 HASTA 7 HACER
    Leer pacientes[i]
  FIN PARA

  Leer nombreBuscado

  posicion = -1   // -1 significa "no encontrado todavía"

  PARA i DESDE 0 HASTA 7 HACER
    SI pacientes[i] es igual a nombreBuscado (sin distinguir mayúsculas) ENTONCES
      posicion = i
      DETENER BÚSQUEDA   // ya lo encontraste, no sigas recorriendo
    FIN SI
  FIN PARA

  SI posicion != -1 ENTONCES
    Imprimir "Encontrado en posición " + posicion
  SI NO
    Imprimir "No encontrado"
  FIN SI
FIN
```

> Pista Java: usa `.equalsIgnoreCase()` en lugar de `==` para comparar Strings sin importar mayúsculas/minúsculas. Usa `break;` para salir del ciclo apenas encuentres el nombre.

### Ejercicio 4.4 — Registro de ventas por sucursal (matriz)

```
INICIO
  Crear matriz ventas[4][3]   // 4 sucursales, 3 productos

  PARA sucursal DESDE 0 HASTA 3 HACER
    PARA producto DESDE 0 HASTA 2 HACER
      Leer ventas[sucursal][producto]
    FIN PARA
  FIN PARA

  // Total por sucursal: sumar cada FILA
  PARA sucursal DESDE 0 HASTA 3 HACER
    totalSucursal = 0
    PARA producto DESDE 0 HASTA 2 HACER
      totalSucursal = totalSucursal + ventas[sucursal][producto]
    FIN PARA
    Imprimir "Sucursal " + sucursal + ": " + totalSucursal
  FIN PARA

  // Total por producto: sumar cada COLUMNA
  PARA producto DESDE 0 HASTA 2 HACER
    totalProducto = 0
    PARA sucursal DESDE 0 HASTA 3 HACER
      totalProducto = totalProducto + ventas[sucursal][producto]
    FIN PARA
    Imprimir "Producto " + producto + ": " + totalProducto
  FIN PARA

  // Venta más alta: recorrer TODA la matriz
  maxVenta = ventas[0][0]
  sucMax = 0, prodMax = 0

  PARA sucursal DESDE 0 HASTA 3 HACER
    PARA producto DESDE 0 HASTA 2 HACER
      SI ventas[sucursal][producto] > maxVenta ENTONCES
        maxVenta = ventas[sucursal][producto]
        sucMax = sucursal
        prodMax = producto
      FIN SI
    FIN PARA
  FIN PARA

  Imprimir maxVenta, sucMax, prodMax
FIN
```

> La diferencia entre "sumar por fila" y "sumar por columna" está en cuál índice mantienes fijo y cuál recorres — dibuja la matriz en papel si te confundes.

### Ejercicio 4.5 — Tablero de tres en raya

```
INICIO
  Crear matriz tablero[3][3], llenar con espacios en blanco

  turno = 1   // 1 = jugador X, 2 = jugador O
  hayGanador = falso
  tableroLleno = falso

  MIENTRAS NO hayGanador Y NO tableroLleno HACER

    simbolo = (turno == 1) ? 'X' : 'O'

    Mostrar tablero
    Imprimir "Turno del jugador " + simbolo

    HACER
      Leer fila, columna
      celdaValida = (fila y columna están entre 0-2) Y (tablero[fila][columna] está vacía)
      SI NO celdaValida ENTONCES
        Imprimir "Celda inválida, intenta de nuevo"
      FIN SI
    MIENTRAS NO celdaValida

    tablero[fila][columna] = simbolo

    hayGanador = verificarGanador(tablero, simbolo)

    // Revisar si el tablero está lleno (para detectar empate)
    tableroLleno = verdadero
    PARA cada celda EN tablero HACER
      SI celda está vacía ENTONCES
        tableroLleno = falso
      FIN SI
    FIN PARA

    SI NO hayGanador ENTONCES
      turno = (turno == 1) ? 2 : 1   // cambiar de jugador
    FIN SI

  FIN MIENTRAS

  Mostrar tablero final

  SI hayGanador ENTONCES
    Imprimir "Ganó el jugador " + simbolo
  SI NO
    Imprimir "Empate"
  FIN SI
FIN


FUNCIÓN verificarGanador(tablero, simbolo):
  // Revisar las 3 filas
  PARA cada fila HACER
    SI las 3 celdas de la fila == simbolo ENTONCES RETORNAR verdadero
  FIN PARA

  // Revisar las 3 columnas
  PARA cada columna HACER
    SI las 3 celdas de la columna == simbolo ENTONCES RETORNAR verdadero
  FIN PARA

  // Revisar las 2 diagonales
  SI diagonal principal == simbolo ENTONCES RETORNAR verdadero
  SI diagonal secundaria == simbolo ENTONCES RETORNAR verdadero

  RETORNAR falso
FIN FUNCIÓN
```

> Este es el ejercicio más largo. Resuélvelo por partes: primero haz que el tablero se imprima bien, luego que permita jugar por turnos sin validar nada, luego agrega la validación de celda ocupada, y al final la función que detecta ganador. No intentes escribirlo todo de una vez.

## Consejos generales para resolver los ejercicios

1. **No abras el editor todavía.** Lee el enunciado dos veces y escribe el pseudocódigo en papel o en un `.txt` antes de tocar Java.

2. **Identifica el tipo de estructura antes de codificar.** Pregúntate: ¿esto es secuencial (una sola pasada), condicional (depende de un valor), o repetitivo (se repite un número de veces o hasta cumplir algo)?

3. **Prueba con datos pequeños primero.** Si tu ciclo debe recorrer un arreglo de 100 elementos, pruébalo mentalmente con 3 elementos antes de asumir que funciona con 100.

4. **Cuando algo no funcione, imprime valores intermedios.** Un `System.out.println("valor de x: " + x);` en medio del código te dice exactamente dónde está el error.

5. **Compara tu pseudocódigo con esta guía solo DESPUÉS de intentarlo tú mismo.** Si copias la lógica sin pensarla, no aprendiste el ejercicio — solo lo transcribiste.
