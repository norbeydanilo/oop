# Manejo de Excepciones en Java
## Try / Catch — Guía práctica con proyecto en VS Code

> Una excepción es un error que ocurre mientras el programa está corriendo. Sin manejo de excepciones, el programa simplemente se detiene y muestra un mensaje de error. Con try/catch, puedes anticiparte a esos errores y decidir qué hacer cuando ocurren.

---

## 1. ¿Qué es una excepción?

Imagina que tu programa le pide al usuario un número y él escribe "hola". O que intenta abrir un archivo que no existe. O que divide un número entre cero. Estos son errores que no ocurren en tiempo de compilación — ocurren **en tiempo de ejecución**, y se llaman **excepciones**.

Sin manejo de excepciones:

```java
int[] numeros = {1, 2, 3};
System.out.println(numeros[10]); // crash: ArrayIndexOutOfBoundsException
System.out.println("Esta línea nunca se ejecuta");
```

Con manejo de excepciones:

```java
try {
    int[] numeros = {1, 2, 3};
    System.out.println(numeros[10]);
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Error: indice fuera del rango.");
}
System.out.println("El programa continua ejecutandose.");
```

## 2. Estructura try / catch / finally

```java
try {
    // Código que puede lanzar una excepción
    // Si ocurre un error aquí, salta inmediatamente al catch

} catch (TipoDeExcepcion e) {
    // Se ejecuta SOLO si ocurrió la excepción del tipo indicado
    // e contiene información sobre el error

} finally {
    // Se ejecuta SIEMPRE — haya o no excepción
    // Útil para cerrar recursos (archivos, conexiones, Scanner)
}
```

El bloque `finally` es **opcional** pero recomendado cuando hay recursos que cerrar.

## 3. Excepciones comunes en Java

| Excepción | Cuándo ocurre |
|---|---|
| `ArithmeticException` | División entre cero: `5 / 0` |
| `NullPointerException` | Usar una variable que es `null` |
| `ArrayIndexOutOfBoundsException` | Acceder a un índice inválido de arreglo |
| `StringIndexOutOfBoundsException` | Acceder a un índice inválido de String |
| `NumberFormatException` | Convertir texto no numérico: `Integer.parseInt("abc")` |
| `ClassCastException` | Convertir un objeto a un tipo incompatible |
| `StackOverflowError` | Recursión infinita |
| `InputMismatchException` | El Scanner recibe un tipo de dato incorrecto |

## 4. Ejemplos de cada excepción

### ArithmeticException

```java
try {
    int resultado = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Error: no se puede dividir entre cero.");
    System.out.println("Detalle: " + e.getMessage());
}
```

### NullPointerException

```java
try {
    String texto = null;
    System.out.println(texto.length()); // null no tiene métodos
} catch (NullPointerException e) {
    System.out.println("Error: la variable no tiene valor asignado.");
}
```

### NumberFormatException

```java
try {
    String entrada = "abc";
    int numero = Integer.parseInt(entrada); // no es un número
} catch (NumberFormatException e) {
    System.out.println("Error: '" + e.getMessage() + "' no es un numero valido.");
}
```

### ArrayIndexOutOfBoundsException

```java
try {
    int[] arr = {10, 20, 30};
    System.out.println(arr[5]); // solo existen índices 0, 1, 2
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Error: indice " + e.getMessage() + " no existe.");
}
```

## 5. Capturar múltiples excepciones

### Varios catch para distintos tipos

```java
try {
    String texto = null;
    int numero   = Integer.parseInt(texto);
    int resultado = numero / 0;

} catch (NullPointerException e) {
    System.out.println("Variable nula: " + e.getMessage());

} catch (NumberFormatException e) {
    System.out.println("Formato invalido: " + e.getMessage());

} catch (ArithmeticException e) {
    System.out.println("Error aritmetico: " + e.getMessage());
}
```

Java ejecuta el primer catch cuyo tipo coincida con la excepción — los demás se saltan.

### Multi-catch (desde Java 7)

```java
try {
    // código con riesgo
} catch (NumberFormatException | ArithmeticException e) {
    System.out.println("Error numerico: " + e.getMessage());
}
```

### Capturar cualquier excepción con `Exception`

```java
try {
    // código con riesgo
} catch (Exception e) {
    // Exception es la superclase de todas las excepciones
    System.out.println("Ocurrio un error: " + e.getMessage());
}
```

> Úsalo con cuidado — capturar todo puede ocultar errores que deberías corregir.

## 6. El bloque finally

```java
Scanner sc = new Scanner(System.in);

try {
    System.out.print("Ingresa un numero: ");
    int numero = sc.nextInt();
    System.out.println("El doble es: " + (numero * 2));

} catch (Exception e) {
    System.out.println("Debes ingresar un numero entero.");

} finally {
    sc.close(); // se ejecuta siempre, haya o no error
    System.out.println("Scanner cerrado.");
}
```

## 7. Información del error

El objeto de excepción `e` tiene métodos útiles:

```java
try {
    int resultado = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());    // "/ by zero"
    System.out.println(e.getClass());      // class java.lang.ArithmeticException
    System.out.println(e.getClass().getSimpleName()); // ArithmeticException
    e.printStackTrace();                   // traza completa del error (útil para depurar)
}
```

## 8. Lanzar excepciones con `throw`

Puedes lanzar una excepción manualmente cuando detectas una condición inválida:

```java
public static double calcularRaiz(double numero) {
    if (numero < 0) {
        throw new ArithmeticException("No se puede calcular la raiz de un numero negativo.");
    }
    return Math.sqrt(numero);
}
```

```java
try {
    System.out.println(calcularRaiz(25));  // 5.0
    System.out.println(calcularRaiz(-4));  // lanza excepción
} catch (ArithmeticException e) {
    System.out.println("Error: " + e.getMessage());
}
```

## 9. Excepciones personalizadas

Puedes crear tus propias excepciones extendiendo `Exception`:

```java
// Tu excepción personalizada
public class SaldoInsuficienteException extends Exception {
    public SaldoInsuficienteException(String mensaje) {
        super(mensaje);
    }
}
```

```java
public class Cuenta {
    private double saldo;

    public Cuenta(double saldo) {
        this.saldo = saldo;
    }

    public void retirar(double monto) throws SaldoInsuficienteException {
        if (monto > saldo) {
            throw new SaldoInsuficienteException(
                "Saldo insuficiente. Disponible: $" + saldo + ", solicitado: $" + monto
            );
        }
        saldo -= monto;
        System.out.println("Retiro exitoso. Saldo restante: $" + saldo);
    }
}
```

```java
Cuenta cuenta = new Cuenta(100000);

try {
    cuenta.retirar(50000);   // OK
    cuenta.retirar(80000);   // lanza SaldoInsuficienteException
} catch (SaldoInsuficienteException e) {
    System.out.println("Error bancario: " + e.getMessage());
}
```

## 10. Crea el proyecto en VS Code

### Estructura

```
ExcepcionesJava/
└── src/
    ├── excepciones/
    │   └── EdadInvalidaException.java
    ├── modelos/
    │   └── Persona.java
    └── App.java
```

### `src/excepciones/EdadInvalidaException.java`

```java
package excepciones;

public class EdadInvalidaException extends Exception {
    public EdadInvalidaException(String mensaje) {
        super(mensaje);
    }
}
```

### `src/modelos/Persona.java`

```java
package modelos;

import excepciones.EdadInvalidaException;

public class Persona {
    private String nombre;
    private int    edad;

    public Persona(String nombre, int edad) throws EdadInvalidaException {
        if (edad < 0 || edad > 120) {
            throw new EdadInvalidaException(
                "Edad invalida: " + edad + ". Debe estar entre 0 y 120."
            );
        }
        this.nombre = nombre;
        this.edad   = edad;
    }

    public String getNombre() { return nombre; }
    public int    getEdad()   { return edad; }

    @Override
    public String toString() {
        return nombre + " (" + edad + " años)";
    }
}
```

### `src/App.java`

```java
import java.util.Scanner;
import java.util.ArrayList;
import modelos.Persona;
import excepciones.EdadInvalidaException;

public class App {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);
        ArrayList<Persona> personas = new ArrayList<>();

        System.out.println("=== REGISTRO DE PERSONAS ===");
        System.out.println("Ingresa 5 personas. Se validara la edad automaticamente.\n");

        int registradas = 0;

        while (registradas < 5) {
            try {
                System.out.print("Nombre: ");
                String nombre = sc.nextLine();

                System.out.print("Edad: ");
                int edad = Integer.parseInt(sc.nextLine()); // puede lanzar NumberFormatException

                Persona p = new Persona(nombre, edad);     // puede lanzar EdadInvalidaException
                personas.add(p);
                registradas++;
                System.out.println("Registrado: " + p + "\n");

            } catch (NumberFormatException e) {
                System.out.println("Error: la edad debe ser un numero entero. Intenta de nuevo.\n");

            } catch (EdadInvalidaException e) {
                System.out.println("Error: " + e.getMessage() + " Intenta de nuevo.\n");

            } finally {
                // Se ejecuta siempre — útil para separar visualmente cada intento
                System.out.println("---");
            }
        }

        System.out.println("\n=== PERSONAS REGISTRADAS ===");
        for (Persona p : personas) {
            System.out.println(p);
        }

        // Calcular promedio de edad con manejo de excepción
        try {
            double promedio = calcularPromedio(personas);
            System.out.println("Promedio de edad: " + promedio);
        } catch (ArithmeticException e) {
            System.out.println("No se puede calcular el promedio: lista vacia.");
        }

        sc.close();
    }

    public static double calcularPromedio(ArrayList<Persona> lista) {
        if (lista.isEmpty()) {
            throw new ArithmeticException("Lista vacia.");
        }
        int suma = 0;
        for (Persona p : lista) {
            suma += p.getEdad();
        }
        return (double) suma / lista.size();
    }
}
```

## 11. Buenas prácticas

- **Captura lo más específico posible** — prefiere `NumberFormatException` sobre `Exception`
- **No captures y silencies** — si capturas, haz algo útil (mostrar mensaje, registrar, reintentar)
- **Usa finally para cerrar recursos** — Scanner, archivos, conexiones de base de datos
- **Crea excepciones propias** cuando la lógica de negocio lo requiere — dan más contexto que las genéricas
- **No uses excepciones para controlar el flujo normal** — son para situaciones excepcionales, no para reemplazar un `if`

```java
// MAL: usar excepción para controlar flujo normal
try {
    int valor = lista.get(indice);
} catch (IndexOutOfBoundsException e) {
    // hacer algo cuando no existe
}

// BIEN: verificar primero
if (indice >= 0 && indice < lista.size()) {
    int valor = lista.get(indice);
}
```

## 12. Resumen

| Bloque | Cuándo se ejecuta |
|---|---|
| `try` | Siempre — contiene el código con riesgo |
| `catch` | Solo si ocurre la excepción del tipo indicado |
| `finally` | Siempre, ocurra o no una excepción |

| Keyword | Para qué |
|---|---|
| `throw` | Lanzar una excepción manualmente |
| `throws` | Declarar que un método puede lanzar una excepción |
| `Exception` | Superclase de todas las excepciones |
| `e.getMessage()` | Obtener el mensaje de error |
| `e.printStackTrace()` | Ver la traza completa del error |
