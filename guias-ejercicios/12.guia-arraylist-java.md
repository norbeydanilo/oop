# ArrayList en Java
## Guía práctica con proyecto en VS Code

> Un ArrayList es una lista dinámica — a diferencia de un arreglo normal, no necesitas saber de antemano cuántos elementos va a tener. Crece y decrece automáticamente.

---

## 1. ¿Por qué ArrayList y no arreglo normal?

Con un arreglo normal:

```java
int[] notas = new int[5]; // debes saber el tamaño desde el principio
notas[0] = 85;
notas[1] = 90;
// si necesitas un 6to elemento... no puedes
```

Con ArrayList:

```java
ArrayList<Integer> notas = new ArrayList<>();
notas.add(85);
notas.add(90);
notas.add(78); // puedes agregar cuantos quieras
notas.add(95);
notas.add(88);
notas.add(100); // sin problema — crece automáticamente
```

---

## 2. Importar ArrayList

ArrayList viene en el paquete `java.util`. Debes importarlo al inicio del archivo:

```java
import java.util.ArrayList;
```

---

## 3. Declaración y creación

```java
// Sintaxis: ArrayList<TipoDeDato> nombre = new ArrayList<>();
ArrayList<String>  nombres = new ArrayList<>();
ArrayList<Integer> edades  = new ArrayList<>();
ArrayList<Double>  precios = new ArrayList<>();

// También puedes indicar una capacidad inicial (opcional, solo como sugerencia)
ArrayList<String> ciudades = new ArrayList<>(10);
```

> **Importante:** ArrayList solo trabaja con **tipos de objeto**, no con tipos primitivos.
> Usa `Integer` en lugar de `int`, `Double` en lugar de `double`, `Character` en lugar de `char`.

| Primitivo | Tipo objeto (wrapper) |
|---|---|
| `int` | `Integer` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

Java convierte automáticamente entre primitivo y objeto (autoboxing):
```java
ArrayList<Integer> lista = new ArrayList<>();
lista.add(42);        // Java convierte int → Integer automáticamente
int n = lista.get(0); // Java convierte Integer → int automáticamente
```

## 4. Operaciones básicas

### Agregar elementos

```java
ArrayList<String> frutas = new ArrayList<>();

frutas.add("Mango");          // agrega al final
frutas.add("Banano");
frutas.add("Naranja");
frutas.add(1, "Fresa");       // agrega en la posición 1 (desplaza los demás)

// Resultado: [Mango, Fresa, Banano, Naranja]
```

### Obtener un elemento

```java
String primera = frutas.get(0); // "Mango" — el índice empieza en 0
String segunda = frutas.get(1); // "Fresa"
```

### Modificar un elemento

```java
frutas.set(0, "Papaya"); // reemplaza "Mango" por "Papaya"
// Resultado: [Papaya, Fresa, Banano, Naranja]
```

### Eliminar un elemento

```java
frutas.remove(2);          // elimina por índice — elimina "Banano"
frutas.remove("Fresa");    // elimina por valor — elimina "Fresa"
// Resultado: [Papaya, Naranja]
```

### Tamaño de la lista

```java
int cantidad = frutas.size(); // 2
```

### Verificar si contiene un elemento

```java
boolean tiene = frutas.contains("Naranja"); // true
boolean no    = frutas.contains("Banano");  // false
```

### Verificar si está vacía

```java
boolean vacia = frutas.isEmpty(); // false
```

### Limpiar la lista

```java
frutas.clear(); // elimina todos los elementos
```

## 5. Recorrer un ArrayList

### Con for-each (la más común)

```java
for (String fruta : frutas) {
    System.out.println(fruta);
}
```

### Con for tradicional (cuando necesitas el índice)

```java
for (int i = 0; i < frutas.size(); i++) {
    System.out.println(i + ": " + frutas.get(i));
}
```

### Con while

```java
int i = 0;
while (i < frutas.size()) {
    System.out.println(frutas.get(i));
    i++;
}
```

## 6. ArrayList de objetos propios

Lo más útil: guardar objetos de tus propias clases.

```java
public class Estudiante {
    private String nombre;
    private double nota;

    public Estudiante(String nombre, double nota) {
        this.nombre = nombre;
        this.nota   = nota;
    }

    public String getNombre() { return nombre; }
    public double getNota()   { return nota; }

    @Override
    public String toString() {
        return nombre + " - Nota: " + nota;
    }
}
```

```java
ArrayList<Estudiante> grupo = new ArrayList<>();

grupo.add(new Estudiante("Ana Torres",   4.5));
grupo.add(new Estudiante("Carlos Rios",  3.8));
grupo.add(new Estudiante("Maria Lopez",  4.9));
grupo.add(new Estudiante("Juan Perez",   2.5));

// Mostrar todos
for (Estudiante e : grupo) {
    System.out.println(e);
}

// Calcular promedio
double suma = 0;
for (Estudiante e : grupo) {
    suma += e.getNota();
}
System.out.println("Promedio: " + (suma / grupo.size()));

// Buscar el mejor estudiante
Estudiante mejor = grupo.get(0);
for (Estudiante e : grupo) {
    if (e.getNota() > mejor.getNota()) {
        mejor = e;
    }
}
System.out.println("Mejor estudiante: " + mejor.getNombre());
```

## 7. Operaciones útiles adicionales

```java
import java.util.ArrayList;
import java.util.Collections;

ArrayList<Integer> numeros = new ArrayList<>();
numeros.add(5);
numeros.add(2);
numeros.add(8);
numeros.add(1);
numeros.add(9);

// Ordenar de menor a mayor
Collections.sort(numeros);
System.out.println(numeros); // [1, 2, 5, 8, 9]

// Ordenar de mayor a menor
Collections.sort(numeros, Collections.reverseOrder());
System.out.println(numeros); // [9, 8, 5, 2, 1]

// Valor máximo y mínimo
System.out.println(Collections.max(numeros)); // 9
System.out.println(Collections.min(numeros)); // 1

// Índice de un elemento
int pos = numeros.indexOf(5); // 2 (posición en la lista ordenada)
```

## 8. Crea el proyecto en VS Code

### Estructura

```
ArrayListJava/
└── src/
    ├── modelos/
    │   └── Producto.java
    └── App.java
```

### `src/modelos/Producto.java`

```java
package modelos;

public class Producto {
    private String nombre;
    private double precio;
    private int    stock;

    public Producto(String nombre, double precio, int stock) {
        this.nombre = nombre;
        this.precio = precio;
        this.stock  = stock;
    }

    public String getNombre() { return nombre; }
    public double getPrecio() { return precio; }
    public int    getStock()  { return stock; }

    public void setStock(int stock) { this.stock = stock; }

    @Override
    public String toString() {
        return nombre + " | $" + precio + " | Stock: " + stock;
    }
}
```

### `src/App.java`

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.Scanner;
import modelos.Producto;

public class App {
    public static void main(String[] args) {

        ArrayList<Producto> inventario = new ArrayList<>();
        Scanner sc = new Scanner(System.in);

        // Agregar productos iniciales
        inventario.add(new Producto("Camiseta",   35000, 50));
        inventario.add(new Producto("Pantalon",   89000, 30));
        inventario.add(new Producto("Zapatos",   150000, 20));
        inventario.add(new Producto("Medias",      8000, 100));
        inventario.add(new Producto("Chaqueta",  220000, 15));

        int opcion;

        do {
            System.out.println("\n=== INVENTARIO ===");
            System.out.println("1. Ver todos los productos");
            System.out.println("2. Agregar producto");
            System.out.println("3. Buscar producto por nombre");
            System.out.println("4. Eliminar producto por nombre");
            System.out.println("5. Producto mas caro y mas barato");
            System.out.println("0. Salir");
            System.out.print("Opcion: ");
            opcion = sc.nextInt();
            sc.nextLine();

            switch (opcion) {

                case 1:
                    System.out.println("\nTotal: " + inventario.size() + " productos");
                    for (int i = 0; i < inventario.size(); i++) {
                        System.out.println((i+1) + ". " + inventario.get(i));
                    }
                    break;

                case 2:
                    System.out.print("Nombre: ");
                    String nombre = sc.nextLine();
                    System.out.print("Precio: ");
                    double precio = sc.nextDouble();
                    System.out.print("Stock: ");
                    int stock = sc.nextInt();
                    sc.nextLine();
                    inventario.add(new Producto(nombre, precio, stock));
                    System.out.println("Producto agregado.");
                    break;

                case 3:
                    System.out.print("Nombre a buscar: ");
                    String buscar = sc.nextLine().toLowerCase();
                    boolean encontrado = false;
                    for (Producto p : inventario) {
                        if (p.getNombre().toLowerCase().contains(buscar)) {
                            System.out.println("Encontrado: " + p);
                            encontrado = true;
                        }
                    }
                    if (!encontrado) System.out.println("No se encontro ningún producto.");
                    break;

                case 4:
                    System.out.print("Nombre a eliminar: ");
                    String eliminar = sc.nextLine().toLowerCase();
                    Producto aEliminar = null;
                    for (Producto p : inventario) {
                        if (p.getNombre().toLowerCase().equals(eliminar)) {
                            aEliminar = p;
                            break;
                        }
                    }
                    if (aEliminar != null) {
                        inventario.remove(aEliminar);
                        System.out.println("Producto eliminado.");
                    } else {
                        System.out.println("Producto no encontrado.");
                    }
                    break;

                case 5:
                    if (inventario.isEmpty()) {
                        System.out.println("Lista vacia.");
                        break;
                    }
                    Producto caro   = inventario.get(0);
                    Producto barato = inventario.get(0);
                    for (Producto p : inventario) {
                        if (p.getPrecio() > caro.getPrecio())   caro   = p;
                        if (p.getPrecio() < barato.getPrecio()) barato = p;
                    }
                    System.out.println("Mas caro:   " + caro);
                    System.out.println("Mas barato: " + barato);
                    break;

                case 0:
                    System.out.println("Saliendo...");
                    break;

                default:
                    System.out.println("Opcion no valida.");
            }

        } while (opcion != 0);

        sc.close();
    }
}
```

## 9. Comparación: arreglo vs ArrayList

| | Arreglo `int[]` | `ArrayList<Integer>` |
|---|---|---|
| Tamaño | Fijo desde el inicio | Dinámico, crece automáticamente |
| Agregar | `arr[i] = valor` | `lista.add(valor)` |
| Obtener | `arr[i]` | `lista.get(i)` |
| Tamaño | `arr.length` | `lista.size()` |
| Eliminar elemento | No se puede directamente | `lista.remove(i)` |
| Buscar | Manual con for | `lista.contains(valor)` |
| Tipos | Primitivos y objetos | Solo objetos (wrappers) |
| Cuándo usarlo | Tamaño conocido y fijo | Tamaño variable o desconocido |

---

## 10. Resumen de métodos

| Método | ¿Qué hace? |
|---|---|
| `add(elemento)` | Agrega al final |
| `add(indice, elemento)` | Agrega en una posición |
| `get(indice)` | Obtiene un elemento |
| `set(indice, elemento)` | Reemplaza un elemento |
| `remove(indice)` | Elimina por posición |
| `remove(objeto)` | Elimina por valor |
| `size()` | Retorna el tamaño |
| `isEmpty()` | Verifica si está vacía |
| `contains(elemento)` | Verifica si existe |
| `indexOf(elemento)` | Retorna la posición |
| `clear()` | Elimina todo |
| `Collections.sort(lista)` | Ordena de menor a mayor |
