# Herencia en Java

## ¿Qué es la herencia?

La herencia permite que una clase **tome los atributos y métodos de otra clase** y los extienda o modifique. La clase que comparte sus características se llama **superclase** (o clase padre), y la que las hereda se llama **subclase** (o clase hijo).

La idea viene del mundo real: un perro *es un* animal, un carro *es un* vehículo, un libro digital *es un* libro. Cuando existe esa relación de "es un", probablemente hay herencia.

> **Regla práctica:** si puedes decir "B *es un tipo de* A", entonces B puede heredar de A.  
> Si solo puedes decir "B *tiene un* A", entonces es una relación (composición o agregación), no herencia.

---

## Sintaxis en Java

```java
public class Subclase extends Superclase {
    // atributos y métodos propios de la subclase
}
```

La palabra clave es `extends`. La subclase **hereda** todos los atributos y métodos `public` y `protected` de la superclase.

---

## Ejemplo: Vehículo, Carro y Moto

Modelamos tres clases:

- `Vehiculo` — superclase con lo que tienen en común todos los vehículos
- `Carro` — subclase que agrega atributos y comportamiento propios
- `Moto` — otra subclase con sus propias características

## El código

### `Vehiculo.java` — la superclase

```java
// Superclase: define lo que tienen en común TODOS los vehículos.
// Carro y Moto heredarán estos atributos y métodos.

public class Vehiculo {

    // Atributos comunes a todo vehículo
    private String marca;
    private int velocidadMax;


    // --- CONSTRUCTORES ---

    public Vehiculo() {
    }

    public Vehiculo(String marca, int velocidadMax) {
        this.marca = marca;
        this.velocidadMax = velocidadMax;
    }


    // --- GETTERS Y SETTERS ---

    public String getMarca() {
        return marca;
    }

    public void setMarca(String marca) {
        this.marca = marca;
    }

    public int getVelocidadMax() {
        return velocidadMax;
    }

    public void setVelocidadMax(int velocidadMax) {
        if (velocidadMax > 0) {
            this.velocidadMax = velocidadMax;
        } else {
            System.out.println("Error: la velocidad debe ser mayor a cero.");
        }
    }


    // --- MÉTODOS ---

    // Estos métodos los heredan Carro y Moto automáticamente
    public void acelerar() {
        System.out.println(marca + " está acelerando.");
    }

    public void frenar() {
        System.out.println(marca + " está frenando.");
    }

    // Este método será sobreescrito por las subclases
    public void mostrarInfo() {
        System.out.println("---- Vehículo ----");
        System.out.println("Marca        : " + marca);
        System.out.println("Vel. máxima  : " + velocidadMax + " km/h");
    }

}
```

---

### `Carro.java` — primera subclase

```java
// Carro HEREDA de Vehiculo con "extends".
// Esto significa que Carro ya tiene marca, velocidadMax,
// acelerar(), frenar() y mostrarInfo() sin necesidad de redefinirlos.
// Solo agregamos lo que es PROPIO de un carro.

public class Carro extends Vehiculo {

    // Atributo propio de Carro — no existe en Vehiculo
    private int puertas;


    // --- CONSTRUCTORES ---

    public Carro() {
    }

    public Carro(String marca, int velocidadMax, int puertas) {
        // super() llama al constructor de la superclase Vehiculo
        // Siempre debe ser la primera línea del constructor
        super(marca, velocidadMax);
        this.puertas = puertas;
    }


    // --- GETTER Y SETTER propios ---

    public int getPuertas() {
        return puertas;
    }

    public void setPuertas(int puertas) {
        if (puertas > 0) {
            this.puertas = puertas;
        }
    }


    // --- MÉTODO PROPIO de Carro ---

    public void abrirBaul() {
        System.out.println("El baúl del " + getMarca() + " está abierto.");
    }


    // --- SOBREESCRITURA de mostrarInfo() ---
    // @Override indica que estamos redefiniendo un método de la superclase.
    // Cuando se llame mostrarInfo() sobre un Carro, se ejecuta ESTA versión.

    @Override
    public void mostrarInfo() {
        // Llamamos al mostrarInfo() de Vehiculo para no repetir código
        super.mostrarInfo();
        // Agregamos la información propia del Carro
        System.out.println("Puertas      : " + puertas);
        System.out.println("Tipo         : Carro");
    }

}
```

### `Moto.java` — segunda subclase

```java
// Moto también hereda de Vehiculo.
// Comparte marca, velocidadMax, acelerar() y frenar() con Carro,
// pero tiene su propio atributo y sobreescribe mostrarInfo().

public class Moto extends Vehiculo {

    // Atributo propio de Moto
    private String tipo;  // "deportiva", "todoterreno", "scooter"


    // --- CONSTRUCTORES ---

    public Moto() {
    }

    public Moto(String marca, int velocidadMax, String tipo) {
        super(marca, velocidadMax);  // llama al constructor de Vehiculo
        this.tipo = tipo;
    }


    // --- GETTER Y SETTER propios ---

    public String getTipo() {
        return tipo;
    }

    public void setTipo(String tipo) {
        this.tipo = tipo;
    }


    // --- MÉTODO PROPIO de Moto ---

    public void hacerCaballito() {
        System.out.println("La " + getMarca() + " está haciendo un caballito.");
    }


    // --- SOBREESCRITURA de mostrarInfo() ---

    @Override
    public void mostrarInfo() {
        super.mostrarInfo();  // reutiliza el mostrarInfo() de Vehiculo
        System.out.println("Tipo         : Moto " + tipo);
    }

}
```

---

### `App.java` — probando todo junto

```java
public class App {

    public static void main(String[] args) {

        // --- Objeto de la superclase ---
        Vehiculo v = new Vehiculo("Genérico", 120);
        v.mostrarInfo();

        System.out.println();

        // --- Objeto Carro ---
        Carro carro = new Carro("Renault", 180, 4);
        carro.mostrarInfo();     // versión sobreescrita de Carro
        carro.acelerar();        // heredado de Vehiculo
        carro.abrirBaul();       // propio de Carro

        System.out.println();

        // --- Objeto Moto ---
        Moto moto = new Moto("Honda", 200, "deportiva");
        moto.mostrarInfo();      // versión sobreescrita de Moto
        moto.frenar();           // heredado de Vehiculo
        moto.hacerCaballito();   // propio de Moto

        System.out.println();

        // --- Polimorfismo dinámico ---
        // Una variable de tipo Vehiculo puede referenciar un Carro o una Moto.
        // Java decide en ejecución cuál mostrarInfo() usar según el objeto real.

        System.out.println("=== Polimorfismo dinámico ===");
        Vehiculo[] flota = new Vehiculo[3];
        flota[0] = new Vehiculo("Base", 100);
        flota[1] = new Carro("Toyota", 160, 4);
        flota[2] = new Moto("Yamaha", 220, "todoterreno");

        for (Vehiculo vehiculo : flota) {
            vehiculo.mostrarInfo();  // cada uno ejecuta SU versión de mostrarInfo()
            System.out.println();
        }

    }

}
```

## Conceptos clave para recordar

| Concepto | Qué hace | Ejemplo |
|---|---|---|
| `extends` | Declara que una clase hereda de otra | `class Carro extends Vehiculo` |
| `super()` | Llama al constructor de la superclase | `super(marca, velocidadMax)` |
| `super.metodo()` | Llama a un método de la superclase | `super.mostrarInfo()` |
| `@Override` | Indica que se sobreescribe un método | `@Override public void mostrarInfo()` |
| Polimorfismo dinámico | Una variable padre referencia un objeto hijo | `Vehiculo v = new Carro(...)` |

## Lo que NO es herencia

```java
// ❌ MAL: un Carro NO "tiene un" Vehiculo — un Carro "ES UN" Vehiculo
public class Carro {
    private Vehiculo vehiculo;  // esto sería composición, no herencia
}

// ✅ BIEN: un Carro "ES UN" Vehiculo
public class Carro extends Vehiculo {
}
```

> La pregunta clave siempre es: ¿puedo decir "un Carro **es un** Vehículo"? Si sí → herencia. ¿Puedo decir "un Carro **tiene un** Motor"? Si sí → composición.
