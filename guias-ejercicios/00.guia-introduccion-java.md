# Introducción a Java
## Guía para estudiantes sin experiencia previa en programación

> Esta guía cubre los fundamentos de Java que necesitas antes de entrar al mundo de la Programación Orientada a Objetos. Si nunca has programado, estás en el lugar correcto.

---

## 1. ¿Qué es Java y cómo funciona?

Java es un lenguaje de programación que le dice a la computadora qué hacer, paso a paso. A diferencia de otros lenguajes, Java tiene una característica especial: **"escríbelo una vez, ejecútalo en cualquier parte"**. Esto significa que el mismo programa funciona en Windows, Mac o Linux sin cambios.

Cuando escribes código Java, el proceso es:

```
Tu código (.java) → Compilador javac → Bytecode (.class) → JVM → Ejecución
```

La **JVM** (Java Virtual Machine) es la que realmente ejecuta el programa. Es como un intérprete universal.

### Tu primer programa

Todo programa en Java parte de esta estructura:

```java
public class MiPrograma {
    public static void main(String[] args) {
        // Aquí va tu código
        System.out.println("Hola, mundo");
    }
}
```

Cosas importantes a notar:
- El **nombre del archivo** debe coincidir exactamente con el nombre de la clase: `MiPrograma.java`
- `main` es el punto de entrada — Java siempre empieza por ahí
- `System.out.println(...)` imprime texto en la consola
- Cada instrucción termina con punto y coma `;`
- Las llaves `{ }` agrupan bloques de código

## 2. Sintaxis básica

### Comentarios

Los comentarios son notas que escribes para explicar el código. Java los ignora al ejecutar.

```java
// Esto es un comentario de una línea

/*
   Esto es un comentario
   de varias líneas
*/
```

Úsalos siempre para explicar qué hace cada parte de tu código.

### Mayúsculas y minúsculas importan

Java distingue entre mayúsculas y minúsculas. `nombre`, `Nombre` y `NOMBRE` son tres cosas diferentes. Por convención:

| Elemento | Convención | Ejemplo |
|---|---|---|
| Clase | PascalCase | `MiClase`, `CuentaBancaria` |
| Variable / método | camelCase | `nombreEstudiante`, `calcularArea()` |
| Constante | SNAKE_CASE_MAYUS | `MAX_INTENTOS`, `PI` |

## 3. Tipos de datos

Un **tipo de dato** le dice a Java qué clase de información vas a guardar. Antes de usar una variable, debes declarar su tipo.

### Tipos primitivos (los más básicos)

```java
// Números enteros
byte   edad = 20;          // -128 a 127
short  año = 2024;         // -32,768 a 32,767
int    poblacion = 50000;  // el más común para enteros
long   distancia = 9000000000L; // números muy grandes (nota la L al final)

// Números decimales
float  temperatura = 36.5f;  // menos precisión (nota la f al final)
double precio = 99.99;       // el más común para decimales

// Carácter (un solo símbolo)
char letra = 'A';           // siempre con comillas simples

// Verdadero o falso
boolean activo = true;
boolean pagado = false;
```

### String: texto (no es primitivo, pero es fundamental)

```java
String nombre = "Ana Torres";      // comillas dobles
String saludo = "Hola, " + nombre; // se concatenan con +
```

### Declaración y asignación

```java
// Declarar y asignar en la misma línea
int edad = 18;

// Declarar primero, asignar después
double nota;
nota = 4.5;

// Desde Java 10: var (el tipo se infiere automáticamente)
var ciudad = "Bogotá"; // Java entiende que es String
```

### Conversión entre tipos (casting)

```java
double precio = 9.99;
int precioCortado = (int) precio; // 9 — pierde los decimales

int entero = 5;
double decimal = entero; // automático: 5.0
```

## 4. Variables y operadores

### Operadores aritméticos

```java
int a = 10, b = 3;

System.out.println(a + b);  // 13 — suma
System.out.println(a - b);  // 7  — resta
System.out.println(a * b);  // 30 — multiplicación
System.out.println(a / b);  // 3  — división entera (¡ojo!)
System.out.println(a % b);  // 1  — módulo (residuo)

// Para división real, uno de los dos debe ser double
System.out.println(10.0 / 3); // 3.3333...
```

> ⚠ **Cuidado:** `10 / 3` en Java da `3`, no `3.33`. Si ambos son `int`, el resultado es `int`.

### Operadores de asignación abreviados

```java
int x = 10;
x += 5;  // x = x + 5 → 15
x -= 3;  // x = x - 3 → 12
x *= 2;  // x = x * 2 → 24
x /= 4;  // x = x / 4 → 6
x++;     // x = x + 1 → 7
x--;     // x = x - 1 → 6
```

### Operadores de comparación (devuelven boolean)

```java
int edad = 20;

System.out.println(edad == 20); // true  — igual a
System.out.println(edad != 18); // true  — diferente de
System.out.println(edad > 18);  // true  — mayor que
System.out.println(edad < 18);  // false — menor que
System.out.println(edad >= 20); // true  — mayor o igual
System.out.println(edad <= 19); // false — menor o igual
```

### Operadores lógicos

```java
boolean mayorDeEdad = true;
boolean tieneCarnet = false;

System.out.println(mayorDeEdad && tieneCarnet); // false — ambos deben ser true
System.out.println(mayorDeEdad || tieneCarnet); // true  — al menos uno true
System.out.println(!mayorDeEdad);               // false — niega el valor
```

## 5. Entrada de datos por consola

Para leer lo que el usuario escribe:

```java
import java.util.Scanner;

public class LeerDatos {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("¿Cómo te llamas? ");
        String nombre = sc.nextLine();

        System.out.print("¿Cuántos años tienes? ");
        int edad = sc.nextInt();

        System.out.println("Hola, " + nombre + ". Tienes " + edad + " años.");

        sc.close();
    }
}
```

Métodos de Scanner más usados:

| Método | Lee |
|---|---|
| `nextLine()` | Una línea completa de texto |
| `next()` | Una palabra (hasta el espacio) |
| `nextInt()` | Un número entero |
| `nextDouble()` | Un número decimal |
| `nextBoolean()` | true o false |

## 6. Estructura secuencial

La estructura más simple: las instrucciones se ejecutan **una tras otra**, en el orden en que están escritas.

```java
public class AreaRectangulo {
    public static void main(String[] args) {
        // Paso 1: declarar variables
        double base = 5.0;
        double altura = 3.0;

        // Paso 2: calcular
        double area = base * altura;

        // Paso 3: mostrar resultado
        System.out.println("El área del rectángulo es: " + area);
    }
}
```

**Ejemplo con entrada del usuario:**

```java
import java.util.Scanner;

public class Promedio {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nota 1: ");
        double nota1 = sc.nextDouble();

        System.out.print("Nota 2: ");
        double nota2 = sc.nextDouble();

        System.out.print("Nota 3: ");
        double nota3 = sc.nextDouble();

        double promedio = (nota1 + nota2 + nota3) / 3;

        System.out.println("Tu promedio es: " + promedio);

        sc.close();
    }
}
```

## 7. Estructura condicional

Permite que el programa tome **decisiones** según una condición. Si la condición es verdadera, ejecuta un bloque; si es falsa, puede ejecutar otro.

### if / else if / else

```java
int nota = 75;

if (nota >= 90) {
    System.out.println("Excelente");
} else if (nota >= 70) {
    System.out.println("Bueno");
} else if (nota >= 60) {
    System.out.println("Aprobado");
} else {
    System.out.println("Reprobado");
}
```

> Solo se ejecuta el primer bloque cuya condición sea `true`. Los demás se saltan.

### if sin llaves (solo para una instrucción)

```java
if (edad >= 18)
    System.out.println("Mayor de edad");
```

Funciona, pero se recomienda siempre usar llaves para evitar errores.

### Operador ternario (forma corta del if)

```java
String mensaje = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
System.out.println(mensaje);
```

Es equivalente a:
```java
String mensaje;
if (edad >= 18) {
    mensaje = "Mayor de edad";
} else {
    mensaje = "Menor de edad";
}
```

### switch (para múltiples opciones exactas)

```java
int dia = 3;
String nombreDia;

switch (dia) {
    case 1:
        nombreDia = "Lunes";
        break;
    case 2:
        nombreDia = "Martes";
        break;
    case 3:
        nombreDia = "Miércoles";
        break;
    default:
        nombreDia = "Día no válido";
        break;
}

System.out.println(nombreDia); // Miércoles
```

> El `break` es importante — sin él, Java continúa ejecutando los casos siguientes.

**Ejemplo completo con entrada:**

```java
import java.util.Scanner;

public class Calculadora {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Número 1: ");
        double a = sc.nextDouble();

        System.out.print("Operación (+, -, *, /): ");
        char op = sc.next().charAt(0);

        System.out.print("Número 2: ");
        double b = sc.nextDouble();

        double resultado;

        if (op == '+') {
            resultado = a + b;
        } else if (op == '-') {
            resultado = a - b;
        } else if (op == '*') {
            resultado = a * b;
        } else if (op == '/' && b != 0) {
            resultado = a / b;
        } else {
            System.out.println("Operación inválida o división por cero.");
            sc.close();
            return;
        }

        System.out.println("Resultado: " + resultado);
        sc.close();
    }
}
```

## 8. Estructura repetitiva

Permite **repetir** un bloque de código múltiples veces. Java tiene tres tipos de ciclos.

### while — "mientras"

Se repite **mientras** la condición sea verdadera. Úsalo cuando no sabes cuántas veces vas a repetir.

```java
int contador = 1;

while (contador <= 5) {
    System.out.println("Vuelta número " + contador);
    contador++; // sin esto, el ciclo nunca termina (ciclo infinito)
}
```

Salida:
```
Vuelta número 1
Vuelta número 2
Vuelta número 3
Vuelta número 4
Vuelta número 5
```

**Ejemplo práctico — validar entrada:**

```java
import java.util.Scanner;

public class ValidarEdad {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int edad = -1;

        while (edad < 0 || edad > 120) {
            System.out.print("Ingresa tu edad (0-120): ");
            edad = sc.nextInt();
            if (edad < 0 || edad > 120) {
                System.out.println("Edad inválida, intenta de nuevo.");
            }
        }

        System.out.println("Edad registrada: " + edad);
        sc.close();
    }
}
```

### do-while — "hacer... mientras"

Igual que `while`, pero **siempre ejecuta el bloque al menos una vez** antes de verificar la condición.

```java
import java.util.Scanner;

public class Menu {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int opcion;

        do {
            System.out.println("\n=== MENÚ ===");
            System.out.println("1. Saludar");
            System.out.println("2. Despedirse");
            System.out.println("0. Salir");
            System.out.print("Opción: ");
            opcion = sc.nextInt();

            if (opcion == 1) {
                System.out.println("¡Hola!");
            } else if (opcion == 2) {
                System.out.println("¡Hasta luego!");
            }
        } while (opcion != 0);

        System.out.println("Programa terminado.");
        sc.close();
    }
}
```

### for — "para"

Úsalo cuando **sabes exactamente cuántas veces** vas a repetir.

```java
// Estructura: for (inicio; condición; actualización)
for (int i = 1; i <= 5; i++) {
    System.out.println("Iteración " + i);
}
```

**Ejemplo — tabla de multiplicar:**

```java
import java.util.Scanner;

public class TablaMultiplicar {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("¿De qué número quieres la tabla? ");
        int numero = sc.nextInt();

        System.out.println("\nTabla del " + numero + ":");
        for (int i = 1; i <= 10; i++) {
            System.out.println(numero + " x " + i + " = " + (numero * i));
        }

        sc.close();
    }
}
```

### Ciclos anidados

Un ciclo dentro de otro. El ciclo interno se ejecuta completo por cada iteración del externo.

```java
// Imprimir una cuadrícula de asteriscos 4x4
for (int fila = 1; fila <= 4; fila++) {
    for (int col = 1; col <= 4; col++) {
        System.out.print("* ");
    }
    System.out.println(); // salto de línea al terminar cada fila
}
```

Salida:
```
* * * *
* * * *
* * * *
* * * *
```

### break y continue

```java
// break — sale completamente del ciclo
for (int i = 1; i <= 10; i++) {
    if (i == 5) break; // para cuando i llega a 5
    System.out.println(i); // imprime 1, 2, 3, 4
}

// continue — salta a la siguiente iteración
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue; // salta los pares
    System.out.println(i); // imprime 1, 3, 5, 7, 9
}
```

## 9. Arreglos (Arrays)

Un arreglo guarda múltiples valores del mismo tipo bajo un solo nombre.

```java
// Declarar un arreglo de 5 enteros
int[] notas = new int[5];

// Asignar valores (el índice empieza en 0)
notas[0] = 85;
notas[1] = 90;
notas[2] = 78;
notas[3] = 92;
notas[4] = 88;

// Declarar y asignar en la misma línea
int[] edades = {18, 20, 22, 19, 21};

// Acceder a un elemento
System.out.println(notas[0]); // 85

// Recorrer con for
for (int i = 0; i < notas.length; i++) {
    System.out.println("Nota " + (i+1) + ": " + notas[i]);
}

// Recorrer con for-each (más simple, cuando no necesitas el índice)
for (int nota : notas) {
    System.out.println(nota);
}
```

**Ejemplo — promedio de un grupo:**

```java
import java.util.Scanner;

public class PromedioGrupo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("¿Cuántos estudiantes hay? ");
        int n = sc.nextInt();

        double[] notas = new double[n];
        double suma = 0;

        for (int i = 0; i < n; i++) {
            System.out.print("Nota del estudiante " + (i + 1) + ": ");
            notas[i] = sc.nextDouble();
            suma += notas[i];
        }

        double promedio = suma / n;
        System.out.println("Promedio del grupo: " + promedio);

        sc.close();
    }
}
```

## 10. Métodos (funciones)

Un método es un bloque de código con nombre que puedes reutilizar. En lugar de repetir el mismo código, lo defines una vez y lo llamas cuando lo necesites.

```java
public class EjemploMetodos {

    // Método que no retorna nada (void) y no recibe parámetros
    public static void saludar() {
        System.out.println("¡Hola!");
    }

    // Método que recibe parámetros
    public static void saludarA(String nombre) {
        System.out.println("¡Hola, " + nombre + "!");
    }

    // Método que retorna un valor
    public static double calcularArea(double base, double altura) {
        return base * altura;
    }

    public static void main(String[] args) {
        saludar();                       // ¡Hola!
        saludarA("María");               // ¡Hola, María!
        double area = calcularArea(5, 3); // area = 15.0
        System.out.println("Área: " + area);
    }
}
```

Ventajas de los métodos:
- **Reutilización** — escribes el código una vez y lo llamas muchas veces
- **Organización** — el código es más fácil de leer y mantener
- **Base de la POO** — los métodos son la esencia del comportamiento de los objetos

## 11. Ejemplo integrador

Un programa que usa todo lo anterior: tipos de datos, entrada, condicional y ciclo.

```java
import java.util.Scanner;

public class SistemaNotas {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("¿Cuántos estudiantes hay en el grupo? ");
        int n = sc.nextInt();
        sc.nextLine(); // limpiar el buffer

        String[] nombres = new String[n];
        double[] notas   = new double[n];
        int aprobados    = 0;
        double sumaTotal = 0;

        // Ingresar datos
        for (int i = 0; i < n; i++) {
            System.out.print("\nNombre del estudiante " + (i + 1) + ": ");
            nombres[i] = sc.nextLine();

            do {
                System.out.print("Nota (0.0 - 5.0): ");
                notas[i] = sc.nextDouble();
                sc.nextLine();
                if (notas[i] < 0 || notas[i] > 5) {
                    System.out.println("Nota inválida.");
                }
            } while (notas[i] < 0 || notas[i] > 5);

            sumaTotal += notas[i];
            if (notas[i] >= 3.0) aprobados++;
        }

        // Mostrar resultados
        System.out.println("\n========== RESULTADOS ==========");
        for (int i = 0; i < n; i++) {
            String estado = (notas[i] >= 3.0) ? "✓ Aprobado" : "✗ Reprobado";
            System.out.println(nombres[i] + ": " + notas[i] + " — " + estado);
        }

        System.out.println("\nPromedio del grupo: " + (sumaTotal / n));
        System.out.println("Aprobados: " + aprobados + " de " + n);
        System.out.println("Reprobados: " + (n - aprobados) + " de " + n);

        sc.close();
    }
}
```

## Resumen

| Concepto | Para qué sirve |
|---|---|
| `int`, `double`, `boolean`, `String` | Guardar diferentes tipos de datos |
| `System.out.println()` | Mostrar información en consola |
| `Scanner` | Leer lo que escribe el usuario |
| `if / else` | Tomar decisiones según condiciones |
| `while` | Repetir mientras se cumpla una condición |
| `for` | Repetir un número conocido de veces |
| `do-while` | Repetir al menos una vez |
| Arreglo `[]` | Guardar múltiples valores del mismo tipo |
| Métodos | Organizar y reutilizar bloques de código |

## ¿Qué sigue?

Con estos fundamentos dominarás el vocabulario de Java. El siguiente paso es la **Programación Orientada a Objetos (POO)**: en lugar de escribir todo en `main`, aprenderás a modelar el mundo real con **clases y objetos** — donde los atributos son las variables que ya conoces, y los métodos son las funciones que acabas de aprender.

> 💡 Todo lo que aprendiste aquí lo seguirás usando dentro de las clases y métodos de la POO. No es un reinicio — es una evolución.
